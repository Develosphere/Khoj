# KHOJ MVP - Demo Guide & Setup Instructions

## 🎯 Overview

KHOJ is an AI-powered investigation platform that transforms raw case information into structured intelligence through automated source collection, evidence extraction, timeline generation, theory formulation, and 3D reconstruction visualization.

## ✅ System Status

**All core modules are integrated and working:**

- ✅ Authentication (Sign up, Login, 2FA)
- ✅ Case Management (Create, View, Update, Delete)
- ✅ Investigation Pipeline (Sources → Evidence → Timeline → Theories)
- ✅ 3D Reconstruction Generation
- ✅ Simulation Viewer

## 🚀 Quick Start

### Prerequisites

- Python 3.14+ installed
- Node.js 18+ and npm installed
- Supabase account with database configured
- Gemini API key

### Backend Setup

```bash
cd backend

# Install dependencies
pip install -r requirements.txt

# Start FastAPI server
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

**Backend will be available at:** http://localhost:8000

### Frontend Setup

```bash
cd frontend

# Install dependencies
npm install

# Start Next.js development server
npm run dev
```

**Frontend will be available at:** http://localhost:3000

## 🎬 Complete User Journey (Demo Script)

### Step 1: Authentication
1. Navigate to http://localhost:3000
2. Click "Sign Up" if new user, or "Sign In" for existing
3. Complete authentication (optional: enable 2FA for enhanced security)
4. Redirects to Dashboard automatically

### Step 2: Dashboard Overview
- View statistics: Total Cases, Active Cases, Sources, Evidence, Theories
- See list of existing investigation cases
- Click "New Investigation" to create a new case

### Step 3: Create Investigation Case
1. Click the "New Investigation" button
2. Fill in:
   - **Case Title:** e.g., "Mir Raza Ali Murder Case"
   - **Case Description:** Brief context (optional)
3. Click "Create Case File"
4. Case appears in the dashboard list

### Step 4: Run AI Analysis Pipeline
1. Click on a case card to open the investigation details
2. Click "Run AI Case Analysis" button
3. Watch the pipeline progress:
   - 🔍 Searching and scraping news sources...
   - 📋 Extracting factual claims via Gemini Flash Lite...
   - ⏱️ Aligning timeline events chronologically...
   - 🧠 Drafting competing theories & evaluating confidence...

**This process takes 30-60 seconds depending on case complexity**

### Step 5: Review Investigation Results
Navigate through the tabs:

#### Sources Tab
- View collected news articles and reports
- See source name, publication date, and content
- Links to original URLs

#### Evidence Tab
- Review extracted claims with AI reasoning
- Check evidence types: forensic, eyewitness, official_statement, circumstantial
- View confidence scores and supporting sources

#### Timeline Tab
- Chronological visualization of events
- Time markers with confidence levels
- Supporting evidence references for each event

#### Theories Tab
- Multiple competing theories generated by AI
- Confidence scores for each theory
- Supporting evidence and timeline event counts
- Click "Generate Reconstruction" on any theory

### Step 6: 3D Reconstruction Visualization
1. Select a theory from the Theories tab
2. Click "Generate Reconstruction"
3. System generates 3D simulation screenplay
4. Navigate to simulation viewer
5. Interactive controls:
   - Play/Pause
   - Timeline scrubber
   - Camera controls
   - Speed adjustment

## 🔧 API Endpoints Reference

### Authentication
- `POST /api/v1/auth/signup` - Create new user account
- `POST /api/v1/auth/login` - Sign in existing user
- `GET /api/v1/auth/user` - Get current user profile

### Cases
- `GET /api/v1/cases/` - List all cases for authenticated user
- `POST /api/v1/cases/` - Create new investigation case
- `GET /api/v1/cases/{id}` - Get case details with all related data
- `PUT /api/v1/cases/{id}` - Update case metadata
- `DELETE /api/v1/cases/{id}` - Delete case and all related data
- `POST /api/v1/cases/{id}/analyze` - **Run complete AI analysis pipeline**
- `POST /api/v1/cases/{id}/sources` - Add source manually to case

### Dashboard
- `GET /api/v1/dashboard/stats` - Get dashboard statistics

### Simulation
- `POST /api/v1/simulation/generate` - Generate 3D reconstruction screenplay
- `GET /api/v1/simulation/{id}` - Retrieve simulation screenplay

## 🎨 Tech Stack

### Backend
- **Framework:** FastAPI (Python)
- **Database:** Supabase (PostgreSQL with RLS)
- **AI:** Google Gemini Flash Lite
- **Search:** DuckDuckGo API, Google News scraper
- **Authentication:** Supabase Auth with JWT

### Frontend
- **Framework:** Next.js 14 (React)
- **Styling:** Tailwind CSS
- **3D Rendering:** Three.js, React Three Fiber
- **State Management:** React Hooks
- **API Client:** Fetch with Supabase Auth integration

## 🐛 Troubleshooting

### Backend Issues

**Import errors:**
```bash
cd backend
python test_quick_check.py  # Verify all imports
```

**Database connection:**
- Check Supabase credentials in `backend/.env`
- Verify RLS policies are configured
- Test with: `python test_pipeline_integration.py`

**API key errors:**
- Verify `GEMINI_API_KEY` is set in `backend/.env`
- Check API quota and limits

### Frontend Issues

**Environment variables:**
- Ensure `frontend/.env.local` exists
- Verify `NEXT_PUBLIC_BACKEND_API_URL=http://localhost:8000`
- Check Supabase credentials match backend

**CORS errors:**
- Verify backend `BACKEND_CORS_ORIGINS` includes `http://localhost:3000`
- Restart both servers after changes

**Build errors:**
```bash
cd frontend
rm -rf .next-dev node_modules package-lock.json
npm install
npm run dev
```

## 🎓 Demo Tips

1. **Prepare test cases in advance:**
   - Use recent, well-covered news events
   - Examples: "Pakistan Quetta bombing 2024", "Hurricane Milton Florida 2024"
   - Avoid obscure or old cases with limited sources

2. **Highlight key features:**
   - Real-time source scraping
   - AI-powered evidence extraction with reasoning
   - Automatic timeline chronology
   - Multiple competing theories
   - 3D visualization generation

3. **Performance expectations:**
   - Source collection: 5-10 seconds
   - Evidence extraction: 15-30 seconds
   - Timeline generation: 10-15 seconds
   - Theory generation: 15-20 seconds
   - Total pipeline: 45-75 seconds

4. **Common demo pitfalls:**
   - API rate limits (Gemini has quotas)
   - Slow internet affecting source collection
   - Case names too specific or obscure
